## 15 分钟结构

- 0:00–3:00：温泉入水、水面与较明显的雨后滴水；山风非常轻。
- 3:00–5:00：滴水间隔逐渐拉开；风吹竹叶开始以独立阵风出现。
- 5:30 附近：一组稍清楚、左右位置不同的屋檐水滴。
- 6:00–8:00：水声稳定，山风与竹叶略有呼吸式起伏。
- 6:00 后：远处虫鸣提高并保持为可辨认的山林层，但仍低于温泉水。
- 10:30：一段 16 秒的竹叶残水滴落。
- 11:00–13:00：进入最稳定阶段，滴水更疏。
- 13:00–15:00：只保留稳定温泉水、很轻山风和少量残滴，末段没有密集事件。

两组屋檐滴水分别安排在 4 / 39 / 82 / 137 / 204 / 292 / 404 / 536 / 701 / 842 秒，以及 20 / 61 / 111 / 171 / 248 / 351 / 468 / 618 / 775 / 875 秒。组内间隔也不相同，因此没有固定 BPM 或“滴、滴、滴”的机械循环。

## 网页控制

开放七个独立声音滑块：

- 温泉入水
- 温泉水面
- 屋檐滴水（同时控制两种滴水变化与竹叶残水）
- 山间晚风
- 风吹竹叶
- 远处虫鸣
- 入水出水

放空模式默认值依次为 35 / 20 / 15 / 10 / 24 / 25 / 28。专注和睡前模式分别降低随机滴水与虫鸣。

## 技术检查

- Demo 平均电平约 -29.0 dBFS，峰值约 -7.6 dBFS，无削波。
- 新主入水平均约 -34.7 dBFS、峰值约 -13.7 dBFS；新水面约 -37.7 dBFS、峰值约 -15.5 dBFS。两者均不含海岸素材。
- 山风约 -43.3 dBFS、湿竹叶约 -48.0 dBFS、虫鸣约 -55.2 dBFS，均处于远景。
- 两组滴水峰值约 -19 至 -20 dBFS，短促但未接近削波。
- 完整文件没有超过 2 秒的异常静音，也没有持续雨声、雷声、人物说话、钟声、风铃或音乐。
